# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User types a note and clicks Save
    Note right of browser: The spa.js form handler calls e.preventDefault() so the page does not reload
    Note right of browser: It creates the note object, pushes it to the local notes list and re-renders the list (redrawNotes)

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    Note right of browser: Body is JSON { "content": "my new note", "date": "..." } with Content-Type: application/json
    activate server
    Note left of server: Server parses the JSON and saves the note
    server-->>browser: 201 Created ({"message":"note created"})
    deactivate server

    Note right of browser: No redirect and no further requests. The browser stays on the same page.
```
